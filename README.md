# InnerTube Web Music Player

A web-based music player utilizing the `youtubei.js` InnerTube wrapper and HTML5 audio.

## Instructions to Run:

1. Make sure you have [Node.js](https://nodejs.org/) installed on your machine.
2. Extract this ZIP archive and open a terminal inside the `yt-web-player` folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local link provided by Vite (e.g., `http://localhost:5173`) in your web browser.
